### 📊 Sistema de Análise de Notas
Este é um sistema simples em Python para registro e análise de notas de alunos, com funcionalidades para calcular estatísticas como média, mediana, moda, desvio padrão, maior e menor nota.

##  Funcionalidades 👨🏾‍💻
Adicionar notas individuais (valores entre 0 e 10).

Gerar relatório estatístico com:

Lista de notas cadastradas

Média

Mediana

Moda (com tratamento para ausência de moda única)

Desvio padrão (se houver pelo menos 2 notas)

Maior e menor nota

# 📦 Requisitos
Python 3.x

Não é necessário instalar bibliotecas externas, pois o projeto utiliza apenas módulos nativos do Python (statistics).

## ▶️ Como executar
Clone este repositório ou copie o arquivo app.py:

```bash
git clone https://github.com/seu-usuario/sistema-analise-notas.git
cd sistema-analise-notas
```

## Execute o script no terminal:

```bash
python app.py
```
Siga o menu interativo para usar as funcionalidades do sistema.
